# Hospital Patient Management System

## Project Overview
A simple C programming project to manage hospital patient records using a menu-driven system.

## Features
- Add new patient details
- Store patient ID, name, age, and disease
- Display all patient records
- Simple menu-driven interface
- Input validation for menu choices

## Technologies Used
- Programming Language: C
- Standard Input/Output Library: `stdio.h`

## How to Run
1. Download or clone this repository.
2. Compile the program using a C compiler:
   `gcc hospital_management.c -o hospital_management`
3. Run the program:
   - Windows: `hospital_management.exe`
   - Linux/macOS: `./hospital_management`

## How to Use
1. Select option 1 to add a patient.
2. Select option 2 to display all patient records.
3. Select option 3 to exit the program.

## Limitations
Patient records are stored in memory and are lost when the program exits. Database integration and permanent storage can be added in future versions.
